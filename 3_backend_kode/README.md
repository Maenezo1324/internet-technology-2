# Задание 3: KODE Internship

В данном репозитории реализованы 3 задачи для стажировки KODE.

## Структура
- `task1_relation.py` — Скрипт алгоритма поиска связи между пользователями (Задача 1).
- `main.py` — FastAPI сервис погоды с кэшированием на 30 минут (Задача 2).
- `DIAGRAM.md` — UML диаграмма архитектуры стажировки (Задача 3).

## Запуск сервиса погоды (Docker)
1. Выполните: `docker-compose up --build -d`
2. API доступно по адресу: `http://localhost:8002/docs`
3. Пример запроса: `GET /weather?city=Moscow`
