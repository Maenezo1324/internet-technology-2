# Продуктовая аналитика: Elfsight

Проект посвящен продуктовой аналитике SaaS-платформы (конструктор виджетов Elfsight). 

## Выполненные задачи:
1. **Customer Journey Map (CJM) & Tracking Plan**: 
   - Построен путь пользователя от лендинга до первой оплаты.
   - Разработан и приоритизирован план отслеживания событий (Event Tracking Plan) для передачи разработчикам.
2. **Аналитический Дашборд**:
   - Сгенерирован синтетический датасет пользователей (Python, Pandas) на основе заданной схемы.
   - Спроектирована структура дашборда для ответа на 9 ключевых бизнес-вопросов.
   - Подготовлена структура презентации для стейкхолдеров с продуктовыми выводами.

## Структура файлов
* `task_1_cjm_tracking.md` — CJM и план разметки событий.
* `task_2_dashboard_presentation.md` — Логика дашборда и презентация.
* `generate_data.py` — Скрипт для генерации `sample_data.csv`.
