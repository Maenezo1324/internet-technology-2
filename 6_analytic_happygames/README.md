# Аналитика данных для Happy Games Studio

Проект содержит решение задачи по SQL-аналитике на больших объемах данных.

## Стек технологий
* **БД**: PostgreSQL 16
* **Объем данных**: > 1 000 000 строк в каждой таблице (`users`, `orders`, `order_items`)
* **Инструменты**: Docker, PostgreSQL.

## Как запустить
1. Запустите контейнер: `docker compose up -d`
2. Дождитесь завершения генерации данных (скрипт `setup.sql` выполняется автоматически при первом запуске).
3. Запустите аналитические запросы: 
   `Get-Content queries.sql | docker exec -i pg_analytic psql -U postgres`

## Решенные задачи
1. Поиск активных пользователей (>10 заказов).
2. Средний чек за последний месяц.
3. Сравнение среднего чека Year-over-Year (текущий год vs прошлый).
4. Топ-10 пользователей по заказам за год.
