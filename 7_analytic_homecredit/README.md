# Оптимизация баз данных (Home Credit Bank)

Решение задач по оптимизации SQL-запросов и импорту сверхбольших объемов данных (Big Data) для СУБД PostgreSQL.

## Задачи в проекте:
1. Удаление дублей в таблице с сохранением автоинкрементного ID.
2. Использование оконных функций (`LEAD`/`LAG`) для вычисления таймлайнов операций без самообъединений (Self-Join).
3. Динамический SQL (PL/pgSQL) для запросов к секционированным таблицам (миллиарды строк).
4. Объединение неполных данных из двух таблиц клиентов (`FULL OUTER JOIN`, `COALESCE`).
5. Проектирование составных индексов для оптимизации JOIN-запросов.
6. Выборки по связанным таблицам (Clients -> Accounts -> Operations) с фильтрацией по диапазонам дат (SARGability).
7. Импорт 20 ГБ CSV файла в PostgreSQL через Python (`psycopg2.copy_expert`).

Все решения с комментариями находятся в файле `solutions.sql`, а скрипт импорта — в `import_csv.py`.
